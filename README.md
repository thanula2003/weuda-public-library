# Weuda Public Library Website

Official website for **Weuda Public Library**, Mawathagama, Kurunegala, Sri Lanka.

The website provides information about the library, its history, books, new book arrivals, photo gallery, official documents, contact information, and other resources for the public.

## Live Website

https://weudapubliclibrary.vercel.app/

## Features

* Library information and history
* Sinhala, English and Tamil language support
* Book showcase
* New book arrivals page
* Photo gallery
* Contact information and opening hours
* Google Maps/location information
* Responsive design for desktop and mobile
* SEO metadata and Open Graph support
* Structured data using Schema.org
* `robots.txt` and `sitemap.xml`
* Google Search verification

## Technologies

* HTML5
* CSS3
* JavaScript

## Library Information

Weuda Public Library was established in **1973** under the Community Week programme.

The website presents information about the library's history, services, collection, members and role within the Mawathagama community.

According to the resources provided, the library has more than **15,293 books** and over **2,600 registered members**.

## SEO

The website includes several SEO-related features:

* Page title and meta description
* Canonical URL
* Open Graph metadata
* Twitter/X card metadata
* Multilingual `hreflang` tags
* Schema.org structured data
* `robots.txt`
* XML sitemap
* Google Search verification
